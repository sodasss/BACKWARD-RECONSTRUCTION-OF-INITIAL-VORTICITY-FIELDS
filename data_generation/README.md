# Data Generation (MATLAB)

This folder contains the MATLAB code used to generate the ground-truth
dataset for training and evaluating the backward reconstruction models
(FNO and ViT-StableFNO).

The data are generated by numerically solving a 2D forced
advection–diffusion (vorticity) equation.

---

## Governing Equation

The vorticity field \( w(x, y, t) \) satisfies

\[
\partial_t w + \mathbf{u} \cdot \nabla w
= \nu \Delta w + f(x, y, t),
\]

where

- \( \mathbf{u} = (u, v) \) is a fixed, divergence-free velocity field,
- \( \nu \) is the viscosity,
- \( f(x, y, t) \) is a prescribed time-dependent forcing.

The velocity field is defined as

\[
u = \pi \cos(\pi y)\sin(\pi x), \quad
v = -\pi \sin(\pi y)\cos(\pi x),
\]

which satisfies incompressibility.

---

## Numerical Method

The PDE is solved using a finite-difference scheme:

- **Spatial discretization**: second-order central differences  
- **Time integration**: explicit Euler method  
- **Boundary conditions**: homogeneous Dirichlet  
- **Grid resolution**: 64 × 64  
- **Domain**: \([0, 1] \times [0, 1]\)

The time step is chosen adaptively according to both advection and
diffusion CFL constraints.

---

## Initial Conditions

For each trajectory, the initial vorticity field is randomly sampled
from one of the following types:

1. **Single Gaussian blob**
2. **Multiple Gaussian blobs**
3. **Random Fourier modes with noise**

This ensures sufficient diversity in the dataset.

---

## Simulation Parameters

- Final time per trajectory: **T = 5.0**
- Saved frames per trajectory: **50**
- Number of trajectories: **2000**
- Viscosity: **ν = 0.01**

---

## Output Files

The MATLAB script generates:

- `w_data.mat`
- `w_data.h5` (recommended)

The HDF5 file contains the following datasets:

- `/data`: shape `(64, 64, 50, 2000)`  
  Vorticity trajectories saved at evenly spaced time steps.
- `/initials`: shape `(64, 64, 2000)`  
  Initial vorticity fields.

---

## Usage in PyTorch Code

The PyTorch training scripts load `w_data.h5` and internally rearrange
the data to shape:

\[
(N, T, H, W),
\]

which is then used to construct backward prediction pairs
\((w_t \rightarrow w_{t-k})\).

---

## Notes

- This MATLAB solver is used **only for data generation**.
- No MATLAB code is required for training or evaluating the neural
  operator models.
- The numerical solver serves as the ground-truth simulator for all
  experiments in this repository.
